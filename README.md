# Автоматизированное тестирование (oleg_tests_new)

## Структура проекта
- `api_tests/` - каталог для тестов API.
- `selenium_tests/` - каталог для UI тестов на Selenium.
  - `fixtures/` - фикстуры для тестов.
  - `locators/` - CSS и XPath локаторы для страниц.
